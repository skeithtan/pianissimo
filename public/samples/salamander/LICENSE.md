# Salamander Grand Piano samples

"Salamander Grand Piano V3" by Alexander Holm, licensed under
[CC-BY 3.0](https://creativecommons.org/licenses/by/3.0/). This folder holds a 30-note,
single-velocity MP3 subset (every minor third, A0–C8) as redistributed by the Tone.js project
(<https://tonejs.github.io/audio/salamander/>). Files are unmodified. Pianissimo credits the
recording in its About/Settings panel. Loaded only when browser sound is explicitly selected.
